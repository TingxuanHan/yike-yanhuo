# 一句话安排与模型接入

更新：2026-10-13。Web“我的日常”和微信首页均提供“一句话安排”入口。手工填写可离线使用；基础AI和自用API需要两端连接同一后端与私人空间。当前实现原生微信页面、共享条件校验器和Node接口；支付宝仅保留平台适配入口。

## 已实现的流程

1. 输入600字内需求，选择基础免费AI、我的API或手工填写。
2. 模型只整理整趟时间、购物预算、出发时刻、明确步速、步行目标、返程偏好、最多三类办事任务和五个商品名称。商品必须来自原文；未知数值留空。
3. 可修改条件，确认前不改地点簿、不调用地图。时间、金额、坐标和价格不能由模型直接生成路线事实。
4. 带入办事后选择候选地点再计算；带入购物时，明确的商品名称替换当前购物草稿，原价格记录保留。规格、单位和数量仍需核对，规格不完整时不能计算。
5. 选定完整行程后进入“顺路动一动”，核对步行目标、等灯假设、停留及返回时间。不把计划当作实际运动。

留空表示保留原设置。明确的步速、出发时刻和步行目标保存到本机地点簿，之后使用已有手动同步流程跨端同步。购物/办事草稿仍是当前设备上的临时输入。服务不可用、超时或限额时保留输入，不自动换到自用付费接口；“手工填写”直接进入同一确认页，不冒充模型结果。

## 开通基础AI

在项目根目录的本机`.env`中填写以下字段，不要提交这个文件。先在服务商控制台核对当前免费模型，再填密钥。

```dotenv
AI_FREE_BASE_URL=https://api.siliconflow.cn/v1
AI_FREE_MODEL=Qwen/Qwen3-8B
AI_FREE_KEY=在本机填入自己的密钥
AI_FREE_SPACE_DAILY=3
AI_FREE_DAILY_REQUESTS=20
AI_FREE_DAILY_TOKEN_BUDGET=60000
AI_OWN_DEVICE_DAILY=20
```

也可以选择OpenRouter：地址`https://openrouter.ai/api/v1`，模型`openrouter/free`，使用该平台自己的密钥。两者选一个即可。没有密钥时基础AI显示“尚未开通”。基础免费指使用者不填写密钥；平台运营者负责供应商账号、预算和服务可用性，并不保证供应商永久免费。

构建后通过`npm start`重启服务以载入配置。正式手机与Web共同使用仍需可达的HTTPS后端及小程序请求域名配置；本地开发工具预览不等于手机已接通模型。

可运行`npm run test:planning-live`查看说明，不会发请求。明确准备好后运行`npm run test:planning-live -- --confirm-one-call`，仅发送一条固定需求，核对四个关键条件；不读私人地点簿、不调用百度、不自动重试、不打印原始响应。该测试使用同一持久化额度库，计入平台日预算。

当前默认使用硅基流动的`Qwen/Qwen3-8B`，关闭思考模式并启用`response_format: {type: "json_object"}`，采用非思考模式的温度0.7与top_p 0.8。JSON模式用于约束格式，程序仍检查字段类型、数值范围和商品来源。提示词明确任务只使用英文代号，数值不带引号或单位。依据：[硅基流动接口文档](https://docs.siliconflow.cn/docs/api/chat-completions-post)、[Qwen3官方模型说明](https://huggingface.co/Qwen/Qwen3-8B)。

Qwen3-8B和此前的`XingChenAGI/Xing4.0-29B`均设置128 token思考上限作为额外约束；答复上限仍为800 token，超时仍为25秒。思考上限纳入本机预算预留，不自动扩容或切换模型。其他模型和服务商不发送这些专用字段。切换基础模型不改变已有设备的自用API设置，也不会重置当天额度。

2026-10-13使用授权密钥对`XingChenAGI/Xing4.0-29B`进行三次推理尝试，并做一次只读模型目录检查。目录返回200且包含该模型；三次规划示例均未通过完整验收，其中第二次约1.6秒返回内容但未通过条件格式校验，第三次25秒超时。第一次使用原测试脚本，仅记录失败，不能据此确定原因。不能将密钥有效或官网免费标价视为规划功能已接通；此轮停止请求，没有提高额度，也未核验账号账单。

## 使用自己的API

连接私人空间后，在“一句话安排 → API设置与额度”选择预设或填写兼容Chat Completions接口的HTTPS基础地址、模型名和完整密钥。保存后密钥输入清空；读取设置只返回地址、模型、是否配置和可用次数，不返回密钥。测试按钮使用已经保存的配置，固定发送一条示例，计入自用额度，也可能被服务商计费。

自用密钥绑定当前设备凭证，不会因家庭空间配对而共享给另一设备。新设备分别配置；删除设置或断开设备连接会删除该凭证的配置。设备到期后需重新连接及配置。数据备份、报告、地点卡、前端包不包含这些密钥。

允许的预设域名为`api.siliconflow.cn`、`openrouter.ai`、`api.deepseek.com`、`api-inference.modelscope.cn`、`api.groq.com`。其他服务商需要管理员在`AI_ALLOWED_HOSTS`加入准确域名，例如`models.example.com`，不能填写协议、路径或端口。当前支持HTTPS 443、Bearer密钥、非流式`/chat/completions`协议；不支持局域网Ollama、不同鉴权协议或任意工具调用。

## 限额与隐私

- 现有身份是配对设备和私人空间，没有实名个人账号；基础额度按空间每天3次，共享该空间的设备合计计算。不能称为严格“每人3次”。全站默认每天最多20次，另受60000估算Token预留预算约束，实际可能先触及估算预算。自用默认每设备20次。
- 请求预先按最大输入字节、输出800 Token和消息开销保守预留。这个数值用于限制请求规模，不是服务商计费Token或人民币硬上限。应在供应商控制台同时设消费限额。失败、超时和连接测试也计入保护次数，不退款重试，避免不明计费重复发生。
- 同一额度数据库跨进程只允许一条模型请求在途；每次25秒超时，无自动重试。服务重启不清空日额度，按北京时间零点重置。数据库记录请求散列、设备散列、空间、日期、模式和预留量，不保存原文或模型输出；七天前请求记录清理。
- 模型仅收到本次文字和固定提取规则，不自动附带地点簿、图片、位置或价格。用户自己写入的敏感内容仍会被发送，所以界面在操作前说明发送范围。输入与确认草稿保存在本机浏览器/微信存储。
- 自用密钥使用AES-256-GCM加密，绑定当前设备散列。默认额度/凭据库为`PERSONAL_DATA_PATH + .ai`，旁边的`.key`文件保存随机主密钥。目录须私有并持久化；数据库和主密钥需一起备份。可用64位十六进制随机`AI_ENCRYPTION_KEY`覆盖文件方式。拥有服务器文件和主密钥权限的管理员仍能解密，这不是对服务器管理员保密的端到端加密。
- 自定义接口先验证允许域名，再验证所有DNS结果为公网地址，连接固定到校验过的地址；不跟随重定向、不转发上游原始错误。AI服务不改变原百度额度、串行队列或真实路线确认流程。
