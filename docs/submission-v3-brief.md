## 02 十五分钟，能满足哪些日常？

社区服务是否便利，取决于居民沿道路实际能走到哪里。跨河绕行、街区出入口与个人步速，都会让“直线很近”和“步行可达”出现差别。设施检索的空白，也可能只是资料没有查全。

| 使用者         | 具体问题                     | 一刻烟火提供的操作                                                  |
| -------------- | ---------------------------- | ------------------------------------------------------------------- |
| 社区工作者     | 哪些服务覆盖不足？           | 选社区 → 看步行范围与六类设施 → 查三类必需设施覆盖 → 补查或比较补点 |
| 日常出门的居民 | 这趟能否按时办完？           | 按步速和时长试算 → 组合买菜、取药等任务 → 核算停留、等待与返程      |
| 长者与家人     | 不会操作或找不到入口怎么办？ | 简易模式、大字地点卡、入口记录；主动发起家人协助，由本人确认建议    |

## 03 地图能力与规划逻辑如何连接

Web 与微信原生小程序共用计算模型和服务接口。地图测时提供路由依据，确定性算法负责核算与比较；AI 负责把自然语言整理成可修改、待确认的出行条件。

1. 交互层：Web ＋ 微信原生小程序：React / TypeScript；微信 JS、WXML、WXSS；地图、地点簿、简易模式与家人协助。
2. 共享计算层：生活圈与整趟规划：采样与边界加密 → 等时圈；设施证据 → 连续覆盖；补点比较；往返、价格记录与步速核算。
3. 服务层：Node.js ＋ SQLite：设备配对、私人空间、版本冲突保护；限流队列、缓存、每日预算、取消与结果保存。
4. 能力层：百度地图 ＋ 可选语音 / AI：地址解析、坐标转换、周边检索、步行路线和底图；语音转文字与结构化条件解析。

### 接口用得深，也要用得省

81 点规则采样，最多增加 96 个边界点，优先细化时间阈值附近的网格；共享边只测一次。路线串行、缓存去重、执行前预检预算，失败结果保留未知。时长切换、个人试算与补点比较复用已有数据。

## 04 让体检结论可以解释，也能行动

| 常见做法的不足         | 本项目的实现与价值                                                                              |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| 用直线圆代表生活圈     | 沿真实步行路线测时，结合阈值附近自适应加密生成近似等时圈，保留断片、空洞与未知区域。            |
| 没搜到设施，就判为缺口 | 区分已有覆盖证据、候选缺口与资料不足；记录检索范围与时间；把不足转成有预算预览的定向补查任务。  |
| 只推荐一个补点位置     | 选择1至3处已测候选点，比较最多7种方案，扣除覆盖重叠；再比较不同步速、等灯假设下的共同补足区域。 |
| 模型直接给一个出行答案 | 语音先转成可编辑文字，AI只提出条件草稿；本人确认后，由路由与约束核算时间、返程和预算。          |

### 同一个判断，留下可核对的依据

1. 先区分：缺设施，还是缺数据？：在地图与报告中查看连续覆盖分区、采样点依据和原始检索时间。
2. 再比较：补哪里，对谁有帮助？：相同新增数量之间比较收益；三种出行条件检查方案是否稳定，资料不足不计为确定收益。
3. 最后验证：另取固定点做接口复核：先冻结预测，再读取分离点位的步行测时；导出误判、漏判和未知，供独立脚本复算。

## 06 体检之外，接到一趟安心出门

普通用户从“我要出门”开始，复杂条件按需展开。社区体检保留完整工作台，长者可以使用简易模式和大字指引。

| 实用场景         | 已经实现的功能                                                                                       |
| ---------------- | ---------------------------------------------------------------------------------------------------- |
| 顺路办事与购物   | 多任务往返；停留与营业等待；根据私人价格、规格和库存记录比较少走、少花与均衡方案；价格不足明确提示。 |
| 记住地图外的小店 | 私人地点簿记录坐标、入口、照片、地标与到访时间；生成地点卡，个人记录不自动变成已核验公共设施。       |
| 长者与家人协作   | 大字、电话入口和短时远程建议；主动位置分享；旧记录带时间与估计范围，建议由本人确认。                 |
| 出门顺便动一动   | 在选定路线安排轻快交替、歇脚与返程；实走记录至少3条有效样本后才建议步速，采用前本人确认。            |
