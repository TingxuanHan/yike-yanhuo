# 演示脚本初稿

建议正式视频3至5分钟；录制前关闭密钥配置页和开发者网络面板。以下操作使用模拟街区，不消耗百度接口配额。

增强版实录位于[`materials/yike-yanhuo-demo.webm`](../materials/yike-yanhuo-demo.webm)，约90秒，带操作说明字幕、无配音，展示模拟操作、覆盖图表、灰色核查网格、核查录入与撤销，以及上海177点加密结果回放。录制脚本使用独立无密钥服务，显式阻断真实分析、底图、定位及转换请求。核查条目为构造记录；上海片段为2026-10-05已有数据，离线示意图不含道路底图；实际地图显示见已验证截图。

| 时间 | 画面与操作 | 讲解要点 |
| --- | --- | --- |
| 0:00-0:25 | 项目首页，指向“模拟街区”标记 | 一刻烟火帮助查看步行范围、民生设施和需要核查的服务空白点。当前展示人工构造案例。 |
| 0:25-1:00 | 选择里巷中心，开始体检；切换5/10/15分钟 | 范围来自道路测时和插值；三个时长复用同一批路线结果。 |
| 1:00-1:35 | 筛选药店、菜市场，点击设施标记 | 地图和清单联动，设施数量按步行时间统计。 |
| 1:35-2:15 | 切换河畔住区，显示覆盖核查点 | 河道和桥梁改变步行路径；1公里设施核查使用独立距离口径。未知数据不能被解释为确实没有设施。 |
| 2:15-2:55 | 打开体检报告，查看来源、采样参数、设施统计和警示 | 每份报告说明输入、范围、调用成本和数据限制，可导出JSON或打印PDF。 |
| 2:55-3:30 | 展示手机布局与源码文档 | 强调可复现测试、密钥代理、路线条数限流、持久化预算和MIT许可证。 |
| 3:30-4:30 | 真实案例联调通过后再插入此段 | 用上海实际地点演示地图与报告，明确入口是否核验、搜索是否完整、哪些结果仍需现场复核。 |

正式成片不得用模拟数据配上海真实案例标题。真实片段优先复用已完成的结果，避免录制时反复消耗配额。未完成入口核验或对照实验时，应明确说明。
