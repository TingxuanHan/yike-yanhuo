# 演示脚本初稿

建议正式视频3至5分钟；录制前关闭密钥配置页和开发者网络面板。以下操作使用模拟街区，不消耗百度接口配额。

## 当前版本的社区体检操作

1. Web打开`http://127.0.0.1:8787/?showcase=1`，或在简易首页点击“社区体检演示”。微信首页也提供该入口。
2. 点击“体验模拟社区”，保留“离线示例／模拟社区”标记，按5、10、15分钟切换，展示色带、对应图例和边界变化；这一过程不重新请求测时。说明空白可能是不可达、未采样或缺测，不能直接认定没有通路。
3. 点击“查设施缺口”，选择类别与核查点。Web也可点击地图上的×或?，查看判定、最近的已检索设施、直线距离、检索完整性和范围限制。将“检索未发现”与“数据不足”分别说明，不把候选缺口当作现场确认。
4. 阅读报告。Web可导出JSON或打印；微信演示提供阅读。需要上海完整报告时从本机已有文件导入，显示原始记录时间；上海实验摘要与当前展示地图相互独立。
5. 展开上海对照摘要，完整呈现三个时长：15分钟加密23/24，5分钟19/24并未全面改善。说明对照来自API测时，入口与设施没有完成现场核验。
6. 微信点击“结束体检演示”恢复原报告和偏好；Web回到“日常首页”，可继续演示简易模式的出门规划与家人协助。

以上入口和新色带已实现；下面链接的视频仍为旧版，正式提交前需按当前代码重录。

## 现有视频与原始分镜

增强版实录位于[`materials/yike-yanhuo-demo.webm`](../materials/yike-yanhuo-demo.webm)，约90秒，带操作说明字幕、无配音，展示模拟操作、覆盖图表、灰色核查网格、核查录入与撤销，以及上海177点加密结果回放。录制脚本使用独立无密钥服务，显式阻断真实分析、底图、定位及转换请求。核查条目为构造记录；上海片段为2026-10-05已有数据，离线示意图不含道路底图；实际地图显示见已验证截图。
