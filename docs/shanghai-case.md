# 上海案例与验证计划

## 首个实测地区

上海市杨浦区四平路街道。候选中心选在抚顺路社区睦邻中心附近（抚顺路与鞍山路交叉口），通过百度地址检索确认位置，并核验实际公共出入口后开始正式实验。

选取理由：成熟居住街区，公共服务类型丰富，有明确的十五分钟生活圈建设背景，可同时检查设施覆盖、入口绕行和街区边界。杨浦区官方报道介绍了该睦邻中心的位置与服务；近期社区报道也可作为场景背景。历史报道不作为当前设施营业情况的证明。

参考：
- [杨浦时报：15分钟步行可达，睦邻服务触手可及](https://yptimes.shyp.gov.cn/html/2021-09/14/content_9405_13885861.htm)
- [杨浦区：四平路街道15分钟社区生活圈报道](https://www.shyp.gov.cn/shypq/xwzx-jzdt/20250110/472007.html)

## 对照实验

1. 核验中心点及入口；保存检索词、坐标系、日期与现场/地图核验依据。
2. 选取至少20个独立验证点，包括5/10/15分钟阈值附近、道路两侧和需要绕行的点。验证点不参与构建等时圈。
3. 对比直线步行圆、固定网格和边界加密网格。分别记录路线条数、请求数、总耗时、边界内外判断一致率和误差分布。
4. 对三类必需设施（菜市场、药店、小学）检查分类误召回、同名分店、入口差异、分页遗漏和临时关闭。
5. 对标为待核查的区域进行独立复核，区分数据遗漏和实际服务缺口。
6. 在同样输入、配额与机器环境下对比请求复用前后开销。
