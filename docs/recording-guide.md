## 成片前可补的一小段

建议补录20—30秒手机预览：简易首页→我的通行需要→模拟行程→备选比较→确认后更新卡片。保留“模拟”标记。使用者此前验证过手机首页切换；本轮新增流程只有业务代码、Web及原生模拟器入口检查，尚没有新的手机实测记录。

若补录现场入口，先取得实际观察并填写时间，不把API地点当作已核验入口；无现场素材时保留当前说明即可。当前彩排未展示AI或语音的真实联网调用，也不声称它们已经在本片中验收。原有介绍与技术PDF仍需在正式提交时同步最新范围。

## 无外部调用的复录

从项目根目录运行，使用独立8790端口、内存私人数据库与新浏览器会话，不改动使用者本机地点簿。先安装项目依赖及Playwright Chromium（Windows可使用已安装Edge）。

```powershell
npm run build
node scripts/record-rehearsal.mjs
$rehearsalTimeline = Get-Content materials/rehearsal-timeline.json -Raw | ConvertFrom-Json
$rehearsalDuration = ($rehearsalTimeline.scenes[-1].end + 100) / 1000
ffmpeg -y -i materials/yike-yanhuo-rehearsal.webm -t $rehearsalDuration -c:v libx264 -crf 21 -preset medium -pix_fmt yuv420p -movflags +faststart -an materials/yike-yanhuo-rehearsal.mp4
```

脚本不载入`.env`，阻断外部请求、真实分析、路线、底图、地址转换及模型／语音推理接口。前半段使用构造街区与明确标注的构造邻里反馈；最后读取仓库中的公开地点API回放。录制成功要求阻断计数为0、浏览器异常为0。若需要重新采集真实数据，应单独审阅并运行实测脚本，不在录制时反复消耗配额。

视频中的家人协助只展示当前本机测试空间，未展示邀请凭证、私人号码、密钥、登录二维码或开发者网络面板。输出为彩排材料，尚未上传小程序、部署云服务或提交赛事。
