# 实走校准与前瞻验证：参赛补充说明

功能基线541d9cf；2026-10-16。与固定提交版v1共同阅读；不改写原视频或既有API实验。

## 01 让个人步速有实走依据

普通步速设置依赖用户猜测。本次补充建立“准备记录、补记实际、比较误差、确认采用”的完整流程：Web和微信共用一套计算与私人同步数据，给个性化15分钟生活圈提供可追溯的步速输入。

| 先后顺序 | 实现与约束 |
| --- | --- |
| 出发前固定预测 | 保存距离、来源、当时步速及已有记录生成的建议；建议记录引用严格早于本次准备的历史。 |
| 走完后填实际 | 纯步行秒数 = 总用时 - 等灯/休息/办事秒数；只纳入同一出门者、已量距离、相近日常走法。 |
| 用户决定应用 | 至少3次且合计300米，使用中位数；差异过大暂不给建议。采用后只改日常步速，旧行程须重新试算。 |

<b>实际原生页面 · 构造布局数据</b>
截图中的记录为测试构造，非居民现场记录。展示当前步速、建议步速、样本数量和用时范围；详细依据默认折叠。

<b>可解释的保护</b>
地图估算、模拟练习、异常步速、超过90天及主动排除的记录不进入日常建议。记录间最大/最小步速比超过1.5时提示重新测量。这里的门槛是产品保护规则，尚未人群验证。

> 应用价值：复用已有百度路线距离重新试算个人可达范围，不新增地图请求；既不把范围当作到达保证，也不把步速换算当作健康评估。只支持一本私人地点簿中的同一位出门者，家人可代填。

## 02 保留改善，也保留失效情形

固定构造对照先提供3次历史，再逐次准备和观察后续记录。基线为当时设置的1.2米/秒，建议为准备时可用历史的中位数。两者在同一批后续记录上比较纯步行秒数的平均绝对误差。

| 构造场景 | 后续数 | 当时设置误差/秒 | 事先建议误差/秒 |
| --- | --- | --- | --- |
| 稳定较慢步速 | 3 | 83.33 | 0 |
| 稳定步速并有等灯停歇 | 3 | 33.33 | 0 |
| 后续走法改变，建议可能更差 | 3 | 0 | 83.33 |
| 历史步速差异过大，暂不给建议 | 0 | - | - |

> 全部为仿真数据，不是现场精度结论。走法改变场景中，历史建议比原设置更差；不能宣称校准必然有效。样本步速范围不是概率或置信区间。
