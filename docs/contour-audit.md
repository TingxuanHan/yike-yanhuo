# 等时圈独立抽点复核

围绕百度任务书的实际路网等时圈、空间插值及真实对比报告，将命令行留出验证接入Web与微信：先冻结报告与预测，再读取固定位置，比较当前轮廓、原规则网格及直线圆。原报告不回填，无新增依赖。

“独立”仅指复核位置与本份报告的采样及设施位置分离，不代表独立地图来源、未见过的最终测试集或现场真值。

## 使用流程

1. 打开原始社区体检报告，选择5、10或15分钟，进入设施核查，展开“抽点复核：这个范围和测时一致吗？”。
2. 选择固定6点或12点，点击“预览固定点与用量”。此时不读取路线，可展开位置及原判断。
3. 模拟模式点击“开始本机复核”，完全离线；真实模式点击“确认读取固定点”，使用现有串行队列和额度。6点最多预留12条路线，12点最多24条，含网关一次重试，不检索设施。
4. 查看三模型的一致数、误判、漏判及有效分母，再展开点记录与读取时间。当前轮廓和直线圆另列共同样本，避免分母不同造成误读。
5. Web导出完整依据，微信复制摘要。改变报告、时长或点数会清除旧结果；取消和页面隐藏忽略迟到响应，失败保留原报告。

此功能要求原始测时报告。个人步速／等灯试算与地图原耗时不同口径，应使用既有[多条件比较](planning-evidence.md)。社区演示退出恢复原页面，不写入私人地点簿。

## 点位与统计规则

复用`HOLDOUT_PROTOCOL`：半径250、600、1000米，每个半径八方向，东为0度、逆时针、起始22.5度。6点取两个对向方向，12点再加两个对向方向。十二点的前六点与六点相同，不按结果选择。

预定义位置与原采样及设施点至少相隔10米，否则停止，不临时移动。复用完整协议时，即使未选入子集的位置过近也会阻止复核，这是保守限制。重复位置再次读取不是新增独立样本，6／12点嵌套不能合并计算总准确率。

当前轮廓保留原几何，规则网格由原粗网格重建，直线圆固定1.2米/秒。若抽点位于范围外、缺少有效三角网格支持或涉及非有效测时顶点，预测显示“资料不足”。空白、孔洞和已证实圈外不可混用。

统计先排除测时缺失，再排除该模型预测不足，二者单列、不重复计数。明确未连接的路线可作不可达对照：预测圈内而测时超限／未连接为误判；预测圈外而测时未超限为漏判，其余已知比较为一致。

只展示固定样本的一致数，不外推社区准确率、面积或人口。不会自动调整模型或删除不利结果；提交性能报告时应事先固定协议并保留全部结果。

## 工程保护与复算

`src/core/contour-audit.ts`负责方案、执行、统计和回放，`src/mini/contour-audit.ts`为两端共用状态机。执行前验证并复制来源，在首次异步读取前冻结预测；每次交给既有Provider一个目的地，不改网关、QPS或重试策略。

`POST /api/contour-audit/preview`返回服务器重算的方案和SHA-256摘要；`POST /api/contour-audit`要求相同报告与摘要、明确确认和请求编号。任务查询／取消复用`/api/analyses/:id`，完成字段为`contourAudit`。沿用设备鉴权、来源检查、任务归属和真实地图任务互斥。重复编号复用任务、变更内容拒绝；内存任务保留最多10分钟，幂等保护不跨服务重启。

预算不足在读取前拒绝；缓存仍由原网关处理并单列命中数。`readAt`为本次读取时间，不保证上游采集时间或缓存内容刚更新。取消时已发出的请求可能计入用量，部分结果不发布；任务编号迟到时补发取消。

导出含原报告、固定预测、冻结／读取时间、全部点记录、指标与用量。回放验证点数、位置、原预测和时间顺序，再重算统计；改动结论会被拒绝。若同时改写输入与结果，复算不能证明来源真实，摘要也不是平台认证。

## 复现与验收

```sh
npm ci
npm run build
npm test
npm run test:ui
npm run benchmark:contour
npm run verify:contour -- .cache/contour-audit/demo-15-12.json
```

`benchmark:contour`重建四组构造数据；`verify:contour`也可复算Web下载的完整文件，不调用网络。手动真实脚本为`scripts/test-contour-audit-live.ts`，需要本机服务、原始百度报告和显式`CONFIRM_BAIDU_AUDIT_LIVE=1`；固定六点、预留12条，不提高限额或自动重复整轮。

244项业务／HTTP／原生页面测试、44项浏览器流程通过。覆盖点位分离、冻结副本、未知、误判漏判、篡改回放、鉴权、任务隔离、摘要绑定、并发重复提交、缓存、预算不足、取消及编号迟到。浏览器实际下载文件交给Node复算，核验320／390／1440像素。微信官方CLI核验标准六点和大字十二点，恢复原页面与字号，未接管桌面；新增手机、跨网络和现场验收待补齐。
