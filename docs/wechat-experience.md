# 微信体验版准备

本轮先交付本机可验证的功能。当前已配置实际小程序AppID，没有云端部署；注册后台的资料审核不等于代码上传或发布。

## 先在开发者工具查看

1. 在项目根目录运行`npm ci`和`npm run build:mini`。
2. 用微信开发者工具导入`miniprogram`目录，确认工具识别了`project.config.json`中已配置的AppID；AppSecret和百度AK不填进小程序。
3. 编译后先查看“附近”离线示例，切换10/15/20分钟，再试大字模式。
4. 在“地点簿”输入名称和地址，拒绝位置选择，保存草稿。重开页面后继续填写，确认草稿未丢失。
5. 按账号后台可用类目与位置接口权限配置`chooseLocation`，填好隐私保护指引，再验证选择入口、照片选取和相机功能。若个人主体没有相关权限，保留草稿入口，不虚构坐标。
6. 新增“一趟出门”可离线核算购物、办事、步行和返程，演练到达、歇脚与行后记录。语音必须先连接可达的后端和私人空间，在后台隐私指引中如实声明录音及第三方识别用途，再做真机授权测试。先核对识别文字，再确认条件变化；普通话噪声、方言与弱网仍需实测。详见[一趟出门与语音](trip-and-voice.md)。

游客模式和浏览器布局预检只能帮助检查开发状态；真实AppID与平台接口权限齐备后，才能完成手机体验。

## 接入同一个后端

Web、小程序共用一个HTTPS源站。已有服务器时按[部署说明](deployment.md)配置`PUBLIC_ORIGIN`、`PERSONAL_DATA_PATH`、创建邀请码及持久化目录，在`miniprogram/config.js`只填公开`apiBaseUrl`，并在微信后台设置对应请求域名。

没有服务器时可以评估CloudBase，但现有SQLite、请求预算和单进程队列不能原样放进会自动销毁的临时文件系统。CloudBase说明其[容器临时存储会随实例回收而清除](https://docs.cloudbase.net/run/deploy/configuring/storage/local)。必须先落实持久化数据库、持久化预算与单实例运行，再迁移；扩为多实例还需共享额度协调。当前没有创建云环境、绑定计费或完成云数据库适配。

本机联调可以手动填写`http://127.0.0.1:8787`，只限同机开发者工具；手机不能通过这个地址访问电脑。公开分享卡和跨设备同步需要实际可访问的HTTPS后端。

运行`npm run check:mini-release`核对AppID、地址和生成文件。该脚本只检查本地配置，不读取密钥，不访问微信后台，不替代认证、备案或提交审核。

## 手机上逐项验收

| 场景 | 通过标准 |
| --- | --- |
| 首次进入、无服务器 | 示例清楚标记为模拟；可看清单和调整时长 |
| 位置隐私拒绝 | 弹窗关闭，可保存地址草稿，不反复要求授权 |
| 选择入口 | 名称与GCJ-02位置保存；打开地图指向所选入口 |
| 真实报告 | 设施点、轮廓和所选地点一致；空洞不被涂为可达 |
| 入口照片 | 相册、相机、横竖照片可保存，超限有恢复提示 |
| 大字模式 | 320—430像素屏幕不横向溢出，键盘不挡主要操作 |
| Web与微信同步 | 照片、收藏和营业时间不丢失；409冲突保留本机数据 |
| 家人卡片 | 未配对设备可看单张卡；不能访问或修改地点簿 |
| 撤销与到期 | 原链接重新打开显示失效；其他卡片不受影响 |
| 无网络、重进页面 | 已保存地点、草稿和可容纳的上次报告仍可读取 |

安卓和iOS各走一遍。原生地图、隐私弹窗、相机、转发和底部安全区，以这些实际结果为准。当前位置与模拟回调测试不能替代现场入口核验。

## 本轮新增功能手机体验

原首页预览和切换已由使用者报告正常。新增页面从“附近 → 出门办事”进入，重新编译后生成新的预览码；旧预览包不会自动获得本轮代码。

1. **一趟办齐**：示例中选择买菜和取药，45分钟包含返程；改成5分钟后应给出调整提示。展开营业时间，试填相同开关门时间，应先拒绝输入而不读取路线。
2. **家人带过的路**：填写两步，选一张不含私人信息的测试照片；退出、重进、保存、逐步查看、复制文字。大字模式下确认照片和按钮不挤出屏幕。
3. **走走歇歇**：示例连续步行上限6分钟；选休息点可得到分段方案，全部取消后应提示当前条件不满足。私人休息点的到期记录不参与计算。
4. **补点看变化**：关闭等灯、步速1.2米/秒，15分钟门槛得到示例新增覆盖3/6点；20分钟门槛为0/6点。两者都是构造路网的可复现结果。

详细步骤见[出门办事](outings.md)。本轮没有开通云服务，也没有调用真实百度接口；需要真实路段时再启动新版后端并按预算使用。熟路与休息点的两端互通已通过本地HTTP测试，手机跨设备同步仍需要可访问的后端。
