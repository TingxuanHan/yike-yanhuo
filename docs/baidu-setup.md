# 百度地图接口开通与费用

核查日期：2026-10-05。实际权限、余额和额度以你自己的控制台为准。

## 现在需要准备什么

进入[百度地图开放平台](https://lbs.baidu.com/)，用百度账号登录，按平台提示完成开发者注册/认证。打开控制台 → 应用管理 → 我的应用 → 创建应用。

建议建立两个应用：

| 应用名称 | 类型 | 用途 |
| --- | --- | --- |
| 一刻烟火-网页地图 | 浏览器端 | 地图底图及覆盖物 |
| 一刻烟火-分析服务 | 服务端 | 地点检索、地理编码、坐标转换、步行批量算路 |

浏览器端设置实际开发地址和正式域名的 Referer 白名单；服务端按当前网络的实际公网出口设置 IP 白名单。`127.0.0.1` 是本地监听地址，不是百度服务器看到的公网出口。无需为了该项目更改系统代理或网络设置。

创建完成后，把对应 AK 填入本地 `.env`。服务端密钥不写入浏览器代码、README、截图或版本历史。不要把服务端 AK 填入 `VITE_` 前缀环境变量。

## 是否付费

官方权益表列出了个人开发者的免费日配额：

| 本项目主要服务 | 个人配额/日 | 表列并发上限 |
| --- | ---: | ---: |
| 地理编码 | 5,000 | 3/秒 |
| 地点检索 | 100 | 3/秒 |
| 步行路线规划（轻量） | 5,000 | 3/秒 |
| 批量算路 | 5,000 | 3/秒 |
| 坐标转换 | 5,000 | 3/秒 |

批量算路的额度和并发按实际路线条数计算，例如1个起点、20个终点计20条，不是1次。开发时先用免费额度验证一个街区；地点检索只有100次/日，分页与反复运行会较快消耗，应设置单次预算并查看控制台用量。

额度超出后才考虑购买相应资源。官方当前搜索配额包展示为300元/12万次，但套餐内容、可购买资格和下单价格应以控制台为准。开发者配额与技术服务授权是不同事项，不能由免费额度推断所有商业用途都免费；比赛是否有专项额度或授权安排可向命题方核实。当前开发无需先购买企业年度套餐。

## 配置后验证顺序

1. 地理编码：查询“上海市杨浦区抚顺路社区睦邻中心”，人工确认位置与入口。
2. 地点检索：只查一个分类，验证权限、范围、分页和返回坐标。
3. 步行测时：先做一对起终点，确认有非零距离与耗时。
4. 坐标转换：用已知测试坐标检查输入输出类型。
5. 浏览器地图：确认底图正常显示、域名限制生效，再运行完整体检。
