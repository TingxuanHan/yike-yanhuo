# 5分钟边界加密复核

2026-10-05。沿用抚顺路社区睦邻中心候选点，实际入口未现场核验。原133点结果与原24点对照保留，本记录不替换此前结果。

## 原因定位与改动

原24点中的5分钟错误发生在200米三角片内部。例如东偏北的一个验证点，顶点线性插值约340秒，接口返回235秒；西南一个点插值约381秒，接口返回274秒。这说明该处稀疏测时不能充分刻画路线绕行。没有证据将这些错误单独归因于入口或地图本身。

新算法保留81点粗网格和最多96个加密点的总预算。首轮最多使用加密预算的三分之二，按5、10、15分钟顺序处理边界；第二轮将剩余预算用于5分钟边界。测到一个边中点后，同时分割其两侧三角形，消除相邻单元使用不同边插值的情况。局部名义间距从200米降到100米，未知测时仍不参与插值。

本案例首轮52个中点全部来自已有记录，第二轮补测44个点，最终177个网格测时点。POI、原采样和设施测时复用旧记录，未重新检索设施。
