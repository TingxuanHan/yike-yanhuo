## 功能验收映射

| 编号 | 验收内容 | 实现与验证证据 |
| --- | --- | --- |
| R01 | 稳定调用地图、坐标转换、地点检索和路径规划 | 浏览器地图；服务端适配器；真实 AK 联调记录 |
| R02 | 基于实际步行耗时生成15分钟可达范围 | 路网测时采样、局部加密、阈值轮廓；与独立路线点对照 |
| R03 | 统计圈内民生设施 | 统一分类、UID及位置去重、设施步行耗时、分页完整性标记 |
| R04 | 识别周边1公里内缺少菜市场、药店或小学的点位 | 连续覆盖分区、面积与逐点依据；保留距离边界、检索不全与范围不足；固定几何对照 |
| R05 | 批量距离计算与工程优化 | 限流、超时、有限重试、请求内复用；记录请求数与路线条数 |
| R06 | 接口异常、限流和地点缺失的恢复 | 可解释错误、未知状态；不将失败结果解释为没有设施 |
| R07 | 清楚、流畅、可操作的地图与报告 | 自定义中心、设施筛选、图例、结果导出、桌面和移动端验证 |
| R08 | 规范的开源工程 | MIT、环境示例、锁文件、自动化测试、CI、部署说明 |

等时圈是基于有限采样的近似结果，精度受采样密度、地图数据和入口位置影响。不得把直线距离圆当作实际路网等时圈；不得将模拟样例表述为真实社区测试结果。
