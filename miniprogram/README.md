# 微信小程序开发版

先在项目根目录执行`npm ci`、`npm run build:mini`，然后用微信开发者工具导入本目录。`shared/`是从共用TypeScript模型构建的产物，不手动修改、不提交。项目已配置实际小程序AppID，导入时使用该账号的管理员或已添加的开发者登录，并将私人开发者工具配置保持在Git之外。

本版为原生JS/WXML/WXSS页面，没有嵌入WebView。首页为“附近、地点簿、我的”。支持原生地图轮廓与设施点、10/15/20分钟切换、分类清单联动、离线示例、入口照片、收藏搜索、地址草稿、大字地点卡、100米实走步速换算、设备配对和共享报告。设施核查编辑仍在Web。

真实地图采用微信原生底图，原始BD-09坐标保留，只在显示和打开地图时本地近似转换为GCJ-02；带空洞的轮廓仅画边线。模拟位置不会打开真实导航。附近清单按估算步行用时排序，最多显示60处，不代表全部设施。调整已有报告的时长和步速在本机完成，不新增百度调用；新起点真实分析仍使用服务器预算保护。

照片在选取后压缩到最长边480像素、约48KB以内，与地点簿一同保存。整个地点簿上限750KB；容量不足会保留输入并提示减少照片。照片、营业时间和收藏在Web与小程序间保留。位置未选定时可先保存地址草稿，补坐标后再入簿。

## 本机联调

1. 在根目录`npm run build`后`npm start`，Web打开`http://127.0.0.1:8787`。
2. Web的“我的日常 → 设备与同步”创建私人地点簿，同步本机记录，生成一次性配对码。
3. 开发者工具内进入“我的 → 家人的地点簿 → 连接设置”，填写同一个本机服务器地址，再输入配对码读取或合并服务器版本。未连接服务器也可体验示例、调整步速和保存地址草稿。
4. localhost仅用于开发者工具同机调试；工具的域名校验需按调试场景配置。手机上的127.0.0.1指向手机自身，不能用它访问电脑。

## 有服务器后的两端联调

按[部署文档](../docs/deployment.md)提供HTTPS服务和持久化卷，设置`PUBLIC_ORIGIN`。小程序配置同一HTTPS域名，并在平台管理后台配置请求域名；实际AppID、位置接口使用权限、隐私保护指引与审核以平台控制台要求为准。位置只在用户主动选择时请求，拒绝后仍可读取已经同步的地点。

本版采用设备配对，不依赖微信AppSecret；未来加入微信登录时，应由服务端完成登录凭证交换，客户端不得携带AppSecret或百度AK。配对设备可访问整个空间，不能把配对码作为公共分享链接。

部署者在`config.js`填写公开的`apiBaseUrl`后，普通用户无需再次输入地址。该文件只放公开地址，不放任何密钥。发布准备执行`npm run check:mini-release`，占位AppID或缺少HTTPS地址会明确提示待完成，不会上传或收费。

## 给家人一张只读地点卡

在地点簿点击“给家人看”，连接服务后选择“生成只读分享卡”，确认分享范围再进入卡片页，通过微信自己的转发按钮发送。没有服务器时仍可复制文字；Web可以打印。

每张卡是生成时的固定副本，七天有效，每个地点簿最多20张有效卡。接收者只能查看这一处地点，不会得到地点簿读写权限。可在“我的 → 已分享的地点卡”撤销；已保存的文字、图片和打印件无法收回。Web生成网页链接，小程序生成小程序卡片，二者共用同一后端卡片数据和撤销机制；暂未实现网页一键跳转小程序或生成微信URL Link。

隐私弹窗使用平台的同意按钮与授权回调，在触发位置或照片接口时显示。后台必须按实际用途填好隐私保护指引；公开分享需要用户额外确认。平台声明、账号权限和隐私弹窗真机行为仍须用真实AppID核验。

`platform/index.js`当前选择微信适配器；`platform/alipay.js`预留了请求、存储、选点和剪贴板接口。后续支付宝仍需AXML/ACSS页面构建、平台配置、位置许可和HTTP方法兼容测试，不能仅切换文件后即声称发布可用。

## 验证边界

办事或购物结果中的“这趟顺路动一动”可将选定路线带入步行节奏页面。支持轻松走、交替走、轻松返程、步行目标与连续上限，沿用已取得的路段距离，不新增地图调用。步行偏好随地点簿同步，草稿留在当前设备；在“一趟办齐”页也能直接打开离线示例。见[步行安排与示例输入](../docs/movement.md)。已验证原生模拟器及双端接口，新增流程仍待手机体验。

“附近 → 出门办事 → 一趟办齐 → 顺路好买”支持购物清单、三类行程比较、补记实付／缺货、消费参考和推荐偏好。先用示例店铺即可离线体验；价格来自私人记录，没有实时价格或库存接入。清单、预算和记录随地点簿同步，手机草稿独立保留。操作、限额与演示输入见[顺路好买](../docs/shopping.md)。新增购物页面已通过业务、双端HTTP与原生模拟器核验，手机体验仍待补齐。

“附近 → 出门办事”提供一趟办齐、家人带过的路、走走歇歇和补点看变化。四项均可先用离线场景体验；熟路和休息点随私人地点簿手动同步。真实新路段需要运行新版后端，沿用现有额度与串行限制；没有服务器时不请求真实路线。功能步骤、候选上限及现场核验要求见[出门办事](../docs/outings.md)。

`tests/mini-contract.test.ts`与`mini-experience.test.ts`执行实际微信页面业务代码和平台适配器，覆盖无密钥HTTP互通、离线试算、拒绝定位后草稿恢复、照片字段、传输大小、分享权限和隐私拒绝。位置、照片及系统回调由测试模拟。另有WXML/WXSS转译的浏览器布局预检。已在微信开发者工具中通过本地接口核验首页和四项出门场景的原生模拟器截图、业务结果及控制台，并修复地点卡页面的无效配置警告。使用者已反馈原首页手机预览和切换正常；新增功能的手机、原生位置和相机接口、位置权限审核与发布验证仍待完成。具体体验步骤见[微信体验版准备](../docs/wechat-experience.md)。
