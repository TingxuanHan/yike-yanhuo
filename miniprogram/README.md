# 微信小程序开发版

先在项目根目录执行`npm ci`、`npm run build:mini`，然后用微信开发者工具导入本目录。`shared/`是从共用TypeScript模型构建的产物，不手动修改、不提交。项目使用游客AppID占位，实际预览/发布需要替换为自己的AppID，并将私人开发者工具配置保持在Git之外。

本版为原生JS/WXML/WXSS页面，没有嵌入WebView。已实现地点簿、大字卡、出行偏好、私人空间配对、共享报告、分析任务与个人出行试算。完整交互地图与设施核查编辑仍在Web。

## 小程序头像

当前头像采用房屋与“15”形道路结合的版本。微信后台可上传[144像素版](../materials/wechat-avatar-v8-144.png)或[512像素版](../materials/wechat-avatar-v8-512.png)，两者均为小于2MB的PNG。[原始图片](../materials/wechat-avatar-v8-original.png)完整保留，先前版本作为历史设计稿保存。

## 本机联调

1. 在根目录`npm run build`后`npm start`，Web打开`http://127.0.0.1:8787`。
2. Web的“我的日常 → 设备与同步”创建私人地点簿，同步本机记录，生成一次性配对码。
3. 开发者工具内填写同一个本机服务器地址和配对码，再读取或合并服务器版本。
4. localhost仅用于开发者工具同机调试；工具的域名校验需按调试场景配置。手机上的127.0.0.1指向手机自身，不能用它访问电脑。

## 有服务器后的两端联调

按[部署文档](../docs/deployment.md)提供HTTPS服务和持久化卷，设置`PUBLIC_ORIGIN`。小程序配置同一HTTPS域名，并在平台管理后台配置请求域名；实际AppID、位置接口使用权限、隐私保护指引与审核以平台控制台要求为准。位置只在用户主动选择时请求，拒绝后仍可读取已经同步的地点。

本版采用设备配对，不依赖微信AppSecret；未来加入微信登录时，应由服务端完成登录凭证交换，客户端不得携带AppSecret或百度AK。配对设备可访问整个空间，不能把配对码作为公共分享链接。

`platform/index.js`当前选择微信适配器；`platform/alipay.js`预留了请求、存储、选点和剪贴板接口。后续支付宝仍需AXML/ACSS页面构建、平台配置、位置许可和HTTP方法兼容测试，不能仅切换文件后即声称发布可用。

## 验证边界

`tests/mini-contract.test.ts`执行实际微信页面业务代码和平台适配器，通过无密钥HTTP服务测试与Web的互通。位置选择回调由测试模拟。尚未进行微信开发者工具的实际渲染、安卓/iOS真机、权限审核与发布验证。
