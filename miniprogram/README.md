# 微信小程序

原生JS/WXML/WXSS页面，与Web共用计算核心，支持附近地图、私人地点簿、出行核算、购物、运动、规划辅助和家人协助。支付宝适配层仅作后续准备。

## 构建与导入

1. 在项目根目录执行 `npm ci` 和 `npm run build:mini`。
2. 用微信开发者工具导入本目录，配置自己的小程序AppID，并使用有权限的开发者账号登录。
3. `shared/`与头像是构建产物，勿手动编辑或提交。头像源文件见 [144像素](../assets/logo-144.png) 和 [512像素](../assets/logo-512.png)。

无服务器时可体验离线示例、个人步速与时长试算、本机草稿。模拟地点不会打开真实地图导航。

## 双端连接

1. 按[部署说明](../docs/deployment.md)启动后端，配置HTTPS和持久化存储。
2. 在 `config.js` 填写公开的 `apiBaseUrl`，在微信后台配置请求域名。
3. Web创建私人空间并生成一次性设备配对码，小程序“我的”中输入配对码连接。
4. 同步前预览合并或替换；版本冲突保留本机草稿。配对码授予整个私人空间访问权，不作公开分享链接。

本机开发者工具可连接电脑的 localhost。手机中的127.0.0.1指向手机自身，真机须连接可达的HTTPS服务。

## 权限与配置

位置、照片、录音均由用户主动触发；按实际用途填写微信隐私保护指引，并验证账号类目及接口权限。拒绝授权后仍可手工填写地址、阅读现有地点或保留文字草稿。

百度AK和模型密钥只存服务端，小程序不能携带AppSecret或供应商密钥。设备配对本身不需要AppSecret。发布前执行 `npm run check:mini-release`，补齐AppID、HTTPS地址及平台配置。

地点照片按最长边480像素和容量限制压缩；地点簿支持私人同步、备份及冲突保护。分享卡是限时只读副本，可撤销；已复制的文字、图片和打印件无法收回。

## 使用边界

真实地图显示采用GCJ-02，原BD-09数据保留，仅显示时近似转换。空洞或缺测不当作可达；已有结果的个性化试算不新增地图调用。真实新路线沿用后端预算与串行保护。

电话、定位、录音、网络和平台隐私授权须在真实手机验收。地图步骤、家人地点线索和估计范围不能替代现场确认。设施台账编辑在Web端；小程序读取共享报告及复核提醒。
