# 一刻烟火

15分钟生活圈智能体检与规划助手，同时提供Web和微信原生小程序。

沿真实道路估算步行范围，解释设施覆盖依据，并把办事、购物、运动与家人协助接到日常出门。

## 演示视频

[观看或下载完整演示（约9分钟，含配音与字幕）](https://github.com/TingxuanHan/yike-yanhuo/releases/download/demo/yike-yanhuo-demo.mp4)

视频中的上海社区使用实际百度地图API；构造示例、历史接口留档和小程序页面分别标注。地图测时与本人记录不能替代现场核验。

## 快速运行

需要Node.js 22.13以上，推荐24。

```sh
npm ci
npm run build
npm start
```

打开 http://127.0.0.1:8787 。无需密钥即可使用构造社区和离线出行示例。开发模式使用 `npm run dev`，访问 http://127.0.0.1:5173 。

真实地图、语音或模型服务按[环境示例](.env.example)在本地 `.env` 配置凭据；勿把密钥放入网页、小程序或Git。部署步骤见[部署说明](docs/deployment.md)，百度设置见[接口配置](docs/baidu-setup.md)。

## 功能

- 社区体检：道路等时圈、分时色带、六类设施、连续覆盖和数据不足提示；支持核查台账、复核提醒、定向补查、补点组合、多条件比较、绕行线索和独立抽点复核。
- 个人出行：自定义时长、步速和出发时间，可选等灯假设及实走校准；办事、购物与运动共同核算往返、营业等待和歇脚。
- 私人地点簿：记录地图未收录的小店、入口照片与地标、到访和营业信息；支持大字、朗读、打印和可撤销的只读卡片。
- 购物与运动：私人价格记录、预算和多店方案比较；沿选定路线安排轻快交替及轻松返程，明确缺价、过期或目标不足。
- 规划辅助：确认式语音转写、基础AI和自用API；先编辑文字与条件，再由本人确认应用，失败保留草稿。
- 家人协助：简易首页、大字、联系家人、主动单次定位、旧地点线索和估计范围、短期位置卡及本人确认的远程建议。
- 邻里反馈：按来源、时效、分歧与通行需要展示门店和路段提醒，保留备选地点及入口确认。
- 双端互通：Web和微信共用计算核心；有服务器时使用设备配对、私人空间、同步、备份与冲突保护。支持报告保存、回放、导出和打印。

信号等待是手工场景假设，价格来自私人记录；不提供实时行人信号、实时库存或安全导航保证。支付宝仅预留平台适配层。

## 微信小程序

```sh
npm run build:mini
```

用微信开发者工具导入 `miniprogram/`，按[小程序说明](miniprogram/README.md)配置自己的AppID。真实手机及双端同步需要可达HTTPS后端和平台允许的请求域名；离线示例可独立体验。

## 验证与维护

```sh
npm run format:check
npm test
npx playwright install chromium
npm run test:ui
```

普通测试和构造对照不调用真实地图或模型。真实API工具仅在显式配置并确认预算后使用，共用串行队列和额度保护。
