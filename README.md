# 一刻烟火

**15分钟生活圈智能体检与规划助手**

从一个社区出发，计算步行能抵达的生活范围，查看买菜、就医、上学与休闲设施，并为待核实的服务缺口留下证据。

参赛方向：2026 上海开源软件应用创新大赛，百度地图“15 分钟生活圈”企业赛题。

## 开发状态

项目处于首轮实现阶段。实测地区选定上海市杨浦区四平路街道，以抚顺路社区睦邻中心附近作为候选分析中心，准确坐标与出入口将在地图接入后核验。

离线样例使用人工构造的道路图和设施，用于复现算法与界面操作，不代表上海真实道路或设施分布。百度地图接口将在本地配置 AK 后启用，真实接口结果、现场对照与性能报告仍需完成。
